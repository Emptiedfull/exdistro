What is ExStore?

ExStore is highly reliable multi nodal distributed kv Store built for performance. It promises secruity over transport along with near instant modification across nodes while maintaining low latency in heavy read-write environments.

Reliable

All operations to any node are always synced to all nodes and unresponsive nodes are kicked from the network. This process ensures all nodes provide reliable and updated info at all times.

Low Latency

By utilizing multithreading and low overhead communicaton all nodes maintain low latency even in high traffic.

Secure

Using asynmmetrical encryption the nodes only communicate on secured channels, no other connection can be established except from trusted sources.

Zero Allocation

All communications and api request handling happens in a zero allocations environment, ensuring minimal overhead.
